# Architecture: TalTech Moodle KEX (Firefox extension)

Read with `design-spec.md` (pixels), `page-designs.md` (per page) and `implementation-plan.md` (order of work). Where a rule says MUST, the implementer follows it literally.

## 1. Goals and hard constraints

- Redesign every student-facing page of `https://moodle.taltech.ee`, client-side only.
- No flash of the old UI. **Fail open:** any error, or a page type we can't handle, leaves a working Moodle page.
- Moodle's own forms and JS keep working (quizzes, submissions, posting).
- Nothing leaves the browser except requests to moodle.taltech.ee made with the user's own session. No remote code, no `eval`, no analytics.
- Dense, keyboard-first, full-width, dark/light, accessible, reduced-motion aware.

## 2. Decisions at a glance

| Topic | Decision |
|---|---|
| Manifest | **Manifest V2** (Firefox). Content scripts and host permissions are granted at install for both temporary and signed installs. MV3 host permissions are user-revocable and were not injected in the Selenium temporary-install test. M0 runs a verification matrix (§3.3) before this is final. |
| Firefox floor | `strict_min_version: "140.0"` (ESR 140; needed for `data_collection_permissions`) |
| Language/tooling | TypeScript + Preact 10 (JSX, automatic runtime) + `@preact/signals`; esbuild bundler; no minification (AMO review friendliness) |
| Rendering | No Shadow DOM. All app CSS nested under `#kex-root` (id specificity beats Bootstrap). Skin CSS scoped to `:root[data-kex="skin"]`. |
| Modes per page | `app` (our view; Moodle DOM hidden but alive), `skin` (Moodle content restyled inside our shell), `off` (pure Moodle plus a small "KEX off" pill) |
| Data | Moodle AJAX (`/lib/ajax/service.php`, batched) first; DOM scraping of the current page or same-origin fetched HTML second. Stale-while-revalidate cache in `browser.storage.local`. |
| Network | `content.fetch` (Firefox: request made as the page, so SameSite=Lax cookies are sent). Falls back to `fetch` in the Chromium test harness. |
| Effects | WebGL2 ribbons shader with toggle; static/fallback image |
| Fonts | Bundled: Inter Variable (UI), Inter Tight Variable (display), JetBrains Mono Variable (mono labels), latin + latin-ext |
| Icons | `lucide-preact` (ISC) |

## 4. Runtime overview

```
document_start ──► kex.css (gate + all styles + @font-face)
               └─► content.js
                    1. boot flags (page localStorage "kex.boot") → html[data-kex=boot|off], theme attrs
                    2. failsafe timer (3s) → failOpen()
                    3. wait for <body> (MutationObserver) → route = resolveRoute(path, body.id, classes)
                    4. mount #kex-root (first child of body) → Shell + View (cached data) → data-kex=app|skin
                    5. DOMContentLoaded → pageinfo, scrapers, skin enhancements
                    6. background revalidation (batched AJAX) → signals → re-render
background.js (event page): browser_action popup bridge, openOptionsPage, storage migrations
popup.html: Enabled / Effects / Theme / Open settings
options.html: full settings, pins export/import, clear data
```

## 5. Boot and the no-flash gate

### 5.1 CSS gate (in `kex.css`, injected before any DOM)
```css
:root:not([data-kex="off"]) body { visibility: hidden; animation: kex-failsafe 0s linear 4s forwards; }
:root:not([data-kex="off"]) #kex-root { visibility: visible; }
@keyframes kex-failsafe { to { visibility: visible; } }
:root[data-kex="app"] body, :root[data-kex="skin"] body { visibility: visible; animation: none; }
:root[data-kex="app"] #page-wrapper { display: none !important; }
:root:not([data-kex="off"]) { background: var(--kex-bg); color-scheme: light dark; }
```
If our JS never runs, the CSS animation reveals Moodle after 4 s. Moodle overlays appended to `<body>` stay visible in app mode: `.modal`, `.modal-backdrop`, `.toast-wrapper` and the session-timeout dialog. Tool user-tour elements (`[data-flexitour]`, `.flexitour`) are hidden in app mode.

### 5.2 JS boot (`src/content/boot.ts`)
1. Read `localStorage.getItem("kex.boot")`. This is a mirror of `{enabled, theme, effects, motion, sidebarCollapsed}`, non-sensitive, and is written whenever settings change.
   - If `enabled === false`: set `data-kex="off"`, schedule the off-pill (§13), and stop.
2. Set these on `<html>`:
   - `data-kex="boot"`;
   - `data-kex-theme="light|dark"` (resolve `system` with `matchMedia('(prefers-color-scheme: dark)')`);
   - `data-kex-effects`;
   - `data-kex-motion="reduced|full"` (reduced if the setting says so or the media query matches);
   - `data-kex-sidebar="full|rail|drawer"`.
   - If `document.documentElement` is null, observe `document` until it exists.
3. `setTimeout(failOpen("timeout"), 3000)`, cleared on successful mount.
4. Body detection: a `MutationObserver` on `documentElement` (childList) resolves as soon as `<body>` is created. The body id is already present at that point.
5. **Not a Moodle page** (no `body.id` starting with `page-`, no `M.cfg` script): set `data-kex="off"` silently (no pill). This covers JSON, XML and error documents.
6. Resolve the route (§6). Create `<div id="kex-root" lang="en">` as `body.firstChild`. Render `<Shell>` and the route view inside a top-level `ErrorBoundary`. Then set `data-kex` to the route mode.
7. Load settings and user data asynchronously (`browser.storage.local`). If the settings differ from the boot mirror, update the mirror and re-apply attributes.

### 5.3 Fail-open and degrade
- **View error** (ErrorBoundary at view level), app mode: `degrade("skin")`. Moodle's page appears inside our shell, with a toast: "Couldn't build this view, showing Moodle's page."
- **Shell error or timeout:** `failOpen()`. Set `data-kex="off"`, unmount `#kex-root` and show the off-pill in its error variant: "KEX hit an error, showing original Moodle. [Retry] [Details]".
- Errors are kept in memory (last 20) for the Details panel. They are never sent anywhere.

## 7. Page context (`src/content/pageinfo.ts`)
`getPageInfo(): PageInfo`, computed once on body detection and finished on DOMContentLoaded.
- `cfg`: `window.wrappedJSObject?.M?.cfg` (Firefox). Fallback: regex `/M\.cfg = (\{.*?\});/` over `document.scripts` text.
- `sesskey`: `cfg.sesskey`, then `a[href*="/login/logout.php?sesskey="]`, then `input[name="sesskey"]`.
- `userId`: `cfg.userId`, then `[data-region="popover-region"][data-userid]`, then `[data-userid]`.
- `courseId`: `cfg.courseId` (1 = site), then `body.className` `/\bcourse-(\d+)\b/`.
- `cmId`: `/\bcmid-(\d+)\b/` from the body class, then `?id=` on `/mod/*/view.php`.
- `contextId`, `pageLayout` (`pagelayout-(\w+)`), `format` (`format-(\w+)`), `lang` (`lang-(\w+)` or `html[lang]`).
- `breadcrumb`: `#page-navbar ol.breadcrumb li` → `{text, href|null}[]`.
- `heading`: `.page-header-headings h1`, then `#page-header h1`, then `h1`. `kicker`: `.page-header-headings .text-uppercase`.
- `isGuest`: `.logininfo` contains a link to `/login/index.php` and there is no `cfg.userId > 1`.
- **The sesskey is kept in memory only. It is never written to storage or logs.**

## 8. Data layer (`src/data/*`)

### 8.1 Transport
```ts
const http = (globalThis as any).content?.fetch?.bind((globalThis as any).content) ?? fetch;
```
`content.fetch` makes the request with the page's principal. Origin is the page, and the `MoodleSession` cookie (SameSite=Lax) is sent on POSTs. All URLs are absolute (`cfg.wwwroot + path`).

### 8.2 Web-service client (`ws.ts`)
- `ws.call<T>(methodname, args, opts?)` returns `Promise<T>`.
- **Batching.** Calls queued in the same macrotask (`setTimeout 0`) are sent as one POST:
  `POST {wwwroot}/lib/ajax/service.php?sesskey={sk}&info={m1,m2,…}`
  body `[{index, methodname, args}, …]`. The response is an array of `{error:false, data}` or `{error:true, exception:{errorcode, message}}`.
- **Errors:**
  - `invalidsesskey` / `servicerequireslogin`: emit `session.expired`. The shell shows a banner "Session expired. [Log in again]" linking to `/login/index.php`. Stop polling.
  - Other `exception`: reject that call only.
  - HTTP or network failure: retry twice (400 ms, 1600 ms), then reject with `NetworkError`.
- In-flight dedupe by `methodname + JSON(args)`.

### 8.5 Cache (`cache.ts`)
- Storage: `browser.storage.local`. Keys are namespaced per user: `kex:v1:{host}:{userId}:{name}`.
- Envelope: `{v:1, at:epochMs, data}`.
- `swr<T>(key, ttlMs, fetcher): Store<T>` returns `{value: Signal<T|undefined>, status: Signal<'idle'|'loading'|'error'>, error, refresh()}`.
  - Reads the cached value synchronously from an in-memory map preloaded at boot (one `storage.local.get(null)` of the user's prefix).
  - Revalidates when older than its TTL.
  - Broadcasts via `storage.onChanged`, so open tabs update live.
- **Scrubbing:** before persisting, deep-walk all strings, remove `sesskey=…` query params, and drop keys named `editurl`, `deleteurl`, `sesskey`, `token`. Raw HTML is never persisted; only parsed fields are.

| Store | TTL | Source |
|---|---|---|
| `courses` (sidebar set) | 6 h (revalidate on every Workspace or My courses load) | timeline classification + prefs |
| `user` | 24 h | users_by_field + DOM |
| `counts` (notifications, messages) | 2 min | popup count + conversations count |
| `state:{courseId}` | 0 (always revalidate in background; render cached) | get_state |
| `cmd:{cmid}` | 30 min, or when `state.statekey` changes | get_module or section.php |
| `tiles:{courseId}` | 7 d | course page DOM |
| `events` | 5 min | action events |
| `recent` | 5 min | recentlyaccesseditems |
| `notifs` | 2 min | popup notifications |
| `grades` | 30 min | scrape |
| `pins` | n/a (user data) | local |
| `ui:{courseId}` | n/a | last topic, tab |

### 8.6 Request budget per page load
- **Shell batch:** at most one POST (courses if stale, counts if stale, user if stale).
- **View batch:** at most one POST. Course page: `get_state` plus `get_module` × the cms in the selected topic.
- **Idle prefetch:** once per hour via `requestIdleCallback`, one POST with `get_state` for all sidebar courses (feeds the palette index).

## 9. Domain model (`src/data/model.ts`)

Name parsing (`src/data/names.ts`):
- **code:** the first `/\b[A-Z]{3}\d{4}\b/` in shortname, then fullname, then idnumber.
- **semester:** `/\((\d{4})\s+(sügis|autumn|kevad|spring|suvi|summer|talv|winter)/i` in fullname. If absent, use the month of the current date: Aug–Jan = autumn (year of August), Feb–Jul = spring.
- **name:** fullname with these removed:
  - leading and trailing codes (all `[A-Z]{3}\d{4}`);
  - parenthesized semester groups and a trailing `(CODE)`.
  Then:
  - if the result contains `" / "`, keep the part after the slash when the UI language is `en`, else the part before;
  - replace `" and "` with `" & "`;
  - collapse whitespace.
- **alias:** user-defined (F2 on a sidebar item); otherwise `name`.
- **Title split for the hero:** if the name contains `" & "`, line 1 is the text before it and line 2 is `"& " + rest`. Otherwise line 2 is the last ⌈40%⌉ of the words (minimum 1). Single-word names use one line, with the gradient on that line.

### 11.3 CSS architecture (MUST)
- Author CSS in `src/styles/**/*.css`, bundled into one `kex.css`. Native nesting is allowed (target Firefox 140).
- **App styles:** every rule is nested under `#kex-root { … }`.
  - Resets use `#kex-root :where(a, button, h1, …)`, specificity (1,0,0).
  - Components use `#kex-root .kex-*`, specificity (1,1,0).
  - This beats Bootstrap's class and element selectors regardless of sheet order.
- **Skin styles:** every rule is prefixed `:root[data-kex="skin"]`. Use `!important` only to beat Bootstrap utility classes, which are themselves `!important`.
- **Tokens:** CSS custom properties `--kex-*`, defined on `:root[data-kex]` and switched by `[data-kex-theme="dark"]`.
- **Gate rules and `@font-face`** live at the top of `kex.css`.
- **Class names:** `kex-` + block, BEM-ish (`kex-row__title`, `kex-row--active`).

### 11.4 State
`@preact/signals` stores (`src/state/*`):
- `settings`, `pageInfo`, `courses`, `courseState`, `cmDetails`, `pins`, `events`, `notifs`, `counts`, `ui`.

Views read signals; actions are plain functions in `src/actions/*`:
- `togglePin`, `toggleDone`, `openCm`, `previewCm`, `setTopic`, `setTab`.

### 11.5 Keyboard manager (`src/lib/keys.ts`)
- One `keydown` listener (capture phase).
- Ignored when the target is `input`, `textarea`, `select`, or `[contenteditable]`, or inside a Moodle `.modal`. Exception: Ctrl+K and Esc.
- Supports chords (`g w`, 1 s timeout). Each scope registers bindings (`global`, `palette`, `course`, `workspace`, `preview`).
- The full map is in `happy-path.md` §7. `?` shows the generated help.

### 11.6 Focus and accessibility

- Skip link "Skip to content".

## 13. Escape hatches

1. **Original page** (`Alt+Shift+O`, palette, Quick settings "KEX on this page" switch).
   - Sets `data-kex="off"`. Session-scoped per route key (`sessionStorage kex.off.<routeKey>`), so it lasts until the tab closes.
   - The off-pill offers "Always for this page type", which writes `settings.routeModes[routeKey] = 'off'`.
2. **Moodle layout in KEX** (palette, app routes only). Sets `data-kex="skin"`: Moodle's own rendering (for example its course format) inside our shell.
3. **Off-pill.**
   - Fixed bottom-left, 32px tall, dark (#201055) pill: "KEX off · Alt+Shift+O".
   - Collapses to a 10px magenta dot after 4 s; expands on hover or focus. Reachable by Tab (last in the document).
   - Error variant: "KEX hit an error. Showing Moodle. [Retry] [Details]".
4. **Global disable.** The toolbar popup "Enabled" switch writes `settings.enabled` and the boot mirror. All pages are then pure Moodle; the pill appears only if `settings.showOffPill` is set.

## 14. Shader subsystem (`src/fx/`)
- **`RibbonsRenderer`** (WebGL2, one full-screen triangle, fragment shader in design-spec §9).
  - API: `new RibbonsRenderer(canvas, {seed, intensity, leftFade})`, `.start()`, `.stop()`, `.renderStatic(t)`, `.resize()`, `.dispose()`.
- **`EffectsController` (singleton) decides the state of every renderer:**
  - `settings.effects`: `animated` | `static` | `off`.
  - `prefers-reduced-motion` or motion setting `reduced`: static.
  - `document.hidden`: stop.
  - IntersectionObserver (threshold 0): stop when offscreen.
  - Frame cap 30 fps (skip alternate rAF ticks).
  - DPR `min(devicePixelRatio, 1.5)`.
- **Adaptive quality.** Measure GPU frame cost via the rAF delta. If the median is over 22 ms across 60 frames, render at 0.66 resolution. If it is still over 22 ms, switch to static.
- **Context loss** (`webglcontextlost`) or no WebGL2: the CSS fallback `background: var(--kex-hero-fallback)`, i.e. a static `url(assets/hero-fallback.webp)` plus a gradient.
- **Determinism for tests.** `settings.debug.freezeTime` (number) renders a single frame at that time.
- **Reuse.** The course hero, Workspace hero, page chrome band (40% intensity), login background (full panel), and video thumbnails. Thumbnails come from one offscreen 268×184 render per seed → `canvas.toDataURL('image/webp')` cached in memory.
- **Limit:** at most 2 live WebGL contexts (hero plus login). Thumbnails share one offscreen context, created on demand and disposed after 5 s idle.
- **Toggle locations:** Quick settings (sidebar Settings), toolbar popup, palette action, options page.

## 15. Slide Up Text (`src/fx/slideup.ts`, `src/ui/components/SlideUpText.tsx`)
API mirrors the 21st.dev/spell.sh component:
```ts
interface SlideUpOptions {
  split?: 'words'|'characters'|'lines';   // default 'words'
  stagger?: number;                       // seconds, default 0.1
  delay?: number;                         // seconds, default 0
  from?: 'first'|'last'|'center';         // default 'first'
  duration?: number;                      // seconds, default 0.5
  ease?: string;                          // default 'cubic-bezier(0.625, 0.05, 0, 1)'
  autoStart?: boolean;                    // default true
  inView?: boolean;                       // default false; once per element
  lines?: 'explicit'|'auto';              // 'explicit' splits on \n (default); 'auto' measures rendered lines
  onStart?: () => void; onComplete?: () => void;
}
function slideUp(el: HTMLElement, text: string, opts?: SlideUpOptions): { play(): void; cancel(): void };
```

DOM structure:
- A visually hidden span holds the full text (for screen readers). The animated pieces are `aria-hidden="true"`.
- **words:** each word is `span.kex-su-clip` (inline-block, overflow hidden, `padding-bottom:.18em; margin-bottom:-.18em`) containing `span.kex-su-item` (inline-block). Spaces are plain text nodes between clips.
- **characters:** words are wrapped in `span.kex-su-word` (`white-space:nowrap`). Each grapheme (`Intl.Segmenter`, falling back to `Array.from`) gets its own clip and item.
- **lines:** one clip per line, with a block display container.

Animation:
- WAAPI on each item: `[{transform:'translateY(110%)'}, {transform:'translateY(0)'}]`, `{duration, delay: delay + staggerDelay(i), easing: ease, fill:'both'}`.
- Stagger delay:
  - first: `i*stagger`
  - last: `(n-1-i)*stagger`
  - center: `|floor(n/2)-i|*stagger`

Behaviour rules:
- **Gradient text** (hero line 2): after layout, set on each item `background-size: <lineWidth>px 100%; background-position: -<offsetLeftInLine>px 0` so the gradient spans the whole line.
- **Reduced motion:** no splitting animation. Render final text immediately and fire `onComplete` synchronously.
- **Re-run:** when `text` changes (the component is keyed by text).

## 20. Installing

**Temporary (development).**
1. Run `npm run build:dev`.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click "Load Temporary Add-on…" and pick `dist/firefox-dev/manifest.json`. Use the prod build for moodle.taltech.ee only.

The add-on is removed on restart.

**Permanent (Firefox release).**
1. Create AMO API credentials at https://addons.mozilla.org/developers/addon/api/key/.
2. `export WEB_EXT_API_KEY=… WEB_EXT_API_SECRET=…`
3. Bump `version` in `manifest/base.json`.
4. Run `npm run build && npm run sign`. Unlisted self-distribution is signed automatically, usually within minutes. The signed `.xpi` lands in `web-ext-artifacts/`.
5. In Firefox: about:addons → ⚙ → "Install Add-on From File…".

Each update repeats steps 3–5 with a higher version. Optional later: set `gecko.update_url` to a self-hosted `updates.json`.

## 21. Security and privacy (MUST)
- Network: only same-origin requests to the Moodle host via `content.fetch`. No other hosts, no telemetry, no remote fonts, scripts or images (Moodle-hosted course images and avatars excepted).
- No `eval`, `new Function`, inline `<script>`, or remote code. Shaders are static strings.
- HTML from Moodle (descriptions, label content, forum text, notifications) goes through `sanitize.ts`:
  - parse with `DOMParser`;
  - allowlisted tags (`p, br, a, strong, em, b, i, u, ul, ol, li, h1–h6, blockquote, code, pre, img, table, thead, tbody, tr, th, td, span, div, sup, sub, hr`);
  - allowlisted attributes (`href` http/https/relative only, `src` same-origin or https, `alt`, `title`, `colspan`, `rowspan`, `lang`, `dir`);
  - strip `on*`, `style`, `srcdoc`;
  - force `rel="noopener"` and `target="_blank"` for external links;
  - inserted with `replaceChildren(fragment)`. Never `innerHTML` with unsanitized data.
- The sesskey lives in memory only. Persisted data is scrubbed (§8.5). Logout and other sesskey links are read from the DOM at click time.
- `data_collection_permissions: none`. The options page states: "KEX stores your settings, pins and a cache of course data in this browser only."
- `web-ext lint` must report 0 errors. Warnings are allowed only with a justification in `docs/decisions.md`.
